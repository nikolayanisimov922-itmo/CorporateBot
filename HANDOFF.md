## 4. Технологии
aiogram 3 (long polling, HTML parse mode, FSM в памяти) · Anthropic Claude (все вызовы —
только в `app/claude_answer.py`, через `_create`, учёт токенов — `app/billing.py`) ·
Notion API (база знаний) + RAG на `intfloat/multilingual-e5-small` · Google Sheets через
сервисный аккаунт (gspread ≥6, файл `google_credentials.json`, почта
`corporatebot@the-formula-508906-b7.iam.gserviceaccount.com`) · faster-whisper (голос, нужен ffmpeg).

**Модели Claude.** `ANTHROPIC_MODEL` — модель всего бота (рекомендовали `claude-haiku-5-5`,
раньше была `claude-haiku-4-5-20251001`). `MGMT_MODEL` — только для «Управление → Спросить»
(рекомендовали `claude-sonnet-5-5`). Для моделей 5-го поколения `_create` сам ставит
`max_tokens ≥ 8000` и `output_config.effort=low` (иначе «мышление» обрезает ответ).
`billing.price_for` понимает модели с датой в названии.

1. **📚 База знаний** — вопрос → поиск по Notion (RAG) → Claude отвечает строго по базе +

   Напоминания (время Дубая UTC+4) с кнопкой: комплектаторам пн (план) и пт (факт) 12:00
   и 15:00; ПМ 1–2 числа (план) и предпоследний/последний день месяца (факт) 12:00, в

## 8. Грабли и решения (важно)
- **Google Workspace компании запрещает делиться файлами общего диска с внешней почтой
  бота** («Аккаунт … не относится к домену Ivan Ogienko»). Решения: файл в «Моём диске»
  Николая; или зеркало (IMPORTRANGE по листам / Apps Script целиком); или админ Workspace
  (Иван) разрешает внешний доступ. Бот на общем диске может значиться редактором, но не
  иметь доступа → ошибка 403/PermissionError.
- **Файл .xlsx в Google Drive** (значок XLSX) бот и IMPORTRANGE НЕ читают → «Файл →
  Сохранить как таблицу Google».
- «Черный ящик» периодически падал с PermissionError (нет доступа к таблице на общем
  диске) — проверять `/sheets_check`; кейсы при сбое приходят админу целиком.
- Ключ Claude однажды истёк (выдан на 30 дней) → новый ключ с «Expires: Never», scope
  «Default workspace».
- В чат попадали секреты на скриншотах (NOTION_TOKEN, BOT_TOKEN) — рекомендовали сменить
  (Notion: my-integrations; бот: @BotFather → Revoke). Просить закрывать ключи на скриншотах.
- Таблица план-факта: «% накоп.» по неделям может ломаться; доверяем итоговому % (W).
- В таблице отпусков на Totals строка 27 без имени (должен быть Бильдешбаев Артур).
- Время на сервере — UTC; везде, где важно, используем Дубай (UTC+4, `expenses.now_dubai`).

## 11. Как тестировать без сервера
Тестовые скрипты лежали во временной папке и не сохранены. Подход: aiogram `Dispatcher`
+ подменённый `Bot.__call__` (собирает SendMessage/EditMessageText), `feed_update` с
фейковыми апдейтами, подменённые Sheets (`spreadsheet()` → объект с `worksheets()` и
`values_batch_get()`), фейковый ответчик Claude, `RegisterUserMiddleware` подключать.
Модули notion_client/google.oauth2/numpy в тестах — заглушки (MagicMock). Для разбора
таблиц — снимки значений (как отдаёт `values_batch_get` с UNFORMATTED_VALUE).
