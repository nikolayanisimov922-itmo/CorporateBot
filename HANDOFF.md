## 1. Что это
Корпоративный Telegram-бот **@IODesignbot** (компания Ivan Ogienko / IO Design).
Написан на Python (aiogram 3). Отвечает на вопросы по базе знаний через Claude,
принимает данные сотрудников в Google Sheets, делает рассылки, фиксирует
договорённости со встреч голосом. Работает 24/7 на сервере Hetzner.

Владелец/админ: Николай. Все ключи у него, он вставляет их сам.
Рабочий процесс: код пишется в чате Claude Code → пушится в GitHub → на сервере
`git pull` + перезапуск службы. Приложение Claude локально НЕ ставится.

## 4. Технологии
- Движок: **aiogram 3** (long polling, без вебхуков)
- Ответы ИИ: **Claude (Anthropic)**, эконом-модель `claude-haiku-4-5`
- Поиск (RAG): локальная модель **intfloat/multilingual-e5-small** (sentence-transformers),
  косинусный поиск на numpy. Индекс лежит в `data/` (gitignored).
- База знаний: **Notion API** (169 страниц), опубликованный сайт
  `mirror-psychology-ae8.notion.site` (для публичных ссылок всем).
- Данные: **Google Sheets** через сервисный аккаунт (gspread). Ключ —
  `google_credentials.json` (создан под ЛИЧНЫМ Gmail, т.к. рабочий Workspace
  блокирует создание ключей сервис-аккаунтов).
- Распознавание речи: локальный **faster-whisper** (модель `small`), нужен ffmpeg.

```

SUPPORT_USERNAME=        # ник в Telegram для раздела «Помощь»
ANTHROPIC_API_KEY=       # ключ Claude
ANTHROPIC_MODEL=claude-haiku-4-5
NOTION_TOKEN=            # секрет интеграции Notion
NOTION_PUBLIC_DOMAIN=mirror-psychology-ae8.notion.site   # ТОЛЬКО домен, без пути
REFRESH_INTERVAL_MIN=60  # автообновление базы из Notion, мин (0 — выкл)
GOOGLE_SHEET_VYRABOTKA=  # ID таблицы «Выработка»
GOOGLE_SHEET_PLANY=      # ID таблицы «Планы»
GOOGLE_SHEET_AGREEMENTS= # ID таблицы «Договорённости»
GOOGLE_CREDENTIALS_FILE=google_credentials.json
PM_IDS=                  # ID проджект-менеджеров через запятую (рассылка ПМ)
KOMPLEKT_IDS=            # ID комплектаторов через запятую
# WHISPER_MODEL=small    # размер модели распознавания (по умолчанию small)
CLAUDE_LOW_BALANCE_USD=2 # предупредить, когда на Claude останется меньше $N
HOSTING_REMINDER_DAY=1   # день месяца для напоминания об оплате Hetzner (0 — выкл)
HOSTING_MONTHLY_COST=    # необязательно, напр. «≈ 5 €» — покажется в напоминании
```
Ключ Google — отдельный файл `google_credentials.json` рядом с bot.py.
С почтой этого сервис-аккаунта расшарены (Editor) все три Google-таблицы.

## 7. Функции бота (главное меню, двуязычное)
1. **📚 База знаний** — вопрос → поиск по Notion (RAG) → Claude отвечает строго по
   базе + публичная ссылка на страницу. Отвечает на языке пользователя (RU/EN).
2. **📤 Передать данные** — Выработка / Планы → пошаговый опрос → строка в свою
   Google-таблицу. Админу приходит уведомление.
3. **🤝 Договорённости** — спрашивает «Какой проект?» (любой текст) → сотрудник
   записывает голосовое → faster-whisper распознаёт → Claude СТРОГО структурирует
   (без домыслов, на языке речи) → строка в таблицу «Договорённости»
   (Дата/Сотрудник/Проект/Расшифровка). Админу — короткое уведомление
   «Сотрудник оставил новую договорённость». Сотруднику — только «✅ Готово».
4. **📢 Рассылка** (только админ) — Общая (текст, уходит ВСЕМ, авто двуязычно
   RU+EN через перевод Claude), ПМ (пятница) и Комплектаторы (пятница) — готовый
   текст конкретным ID. Предпросмотр → подтверждение → отчёт доставлено/заблок.
5. **🔄 Обновить базу** (только админ) — перечитать Notion сейчас (+ показывает,
   сколько добавилось/изменилось/удалилось).
6. **💰 Баланс** (только админ) — сколько осталось на Claude (подсчёт бота по
   токенам с момента последнего пополнения). После пополнения админ вводит сюда
   новый баланс в $. Уведомления админу в личку:
   - ⚠️ остаток ниже `CLAUDE_LOW_BALANCE_USD` (один раз до следующего пополнения);
   - 🔴 Claude отказал из-за денег (ошибка 402 / «credit balance too low»),
     не чаще раза в 3 часа;
   - 💳 раз в месяц (`HOSTING_REMINDER_DAY`, с 10:00) — напоминание, что Hetzner
     спишет оплату с карты. У Hetzner постоплата и нет API баланса, поэтому
     только напоминание. Состояние — `data/billing.json`.
   Точный баланс Claude обычным ключом API не узнать — отсюда ручной ввод.
7. **ℹ️ Помощь** — описание + контакт админа. **🌐 English / Русский** — язык.

## 9. Процесс рабочего дня / договорённостей (для людей)
Очная встреча с клиентом → сотрудник в тот же день открывает бота →
«🤝 Договорённости» → проект → голосовое → бот фиксирует в таблицу → админу
уведомление → админ публикует договорённости во внутренний чат проекта в Telegram,
тегает сотрудника → сотрудник перепроверяет → отправляет клиенту в WhatsApp-группу.
Админ следит за таблицей договорённостей. (Регламент Николай допишет отдельно.)
