# Этап 9. Хостинг — бот работает 24/7 без вашего компьютера

## Важно понимать про этого бота

Поиск по базе использует локальную ИИ-модель — ей нужно **≥ 1 ГБ оперативной памяти**
(лучше 2 ГБ). Поэтому самые дешёвые тарифы «на 512 МБ» не подойдут — бот там не
запустится. Выбирайте хостинг с памятью от 1–2 ГБ.

Бот работает на «длинных опросах», публичный адрес не нужен. **Важно:** одновременно
должен работать только ОДИН экземпляр бота. Когда запустите на хостинге — остановите
бота на своём Mac (`Ctrl+C`), иначе Telegram будет ругаться на конфликт.

Проект уже готов «под переезд»: при первом запуске на сервере бот сам скачает базу из
Notion и построит поиск (первый старт ~1–2 минуты).

## Вариант A — Railway (проще, без администрирования сервера)

1. Зайдите на https://railway.app → **Login with GitHub**.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий **CorporateBot**
   и ветку `claude/tender-darwin-pjbv25`.
3. Railway сам поставит зависимости (`requirements.txt`) и запустит `python bot.py`
   (команда из `Procfile`).
4. Откройте вкладку **Variables** и добавьте по одной переменной (значения — из вашего
   файла `.env`):

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен бота |
   | `ADMIN_ID` | ваш числовой ID |
   | `SUPPORT_USERNAME` | ваш ник (без @) |
   | `ANTHROPIC_API_KEY` | ключ Claude |
   | `ANTHROPIC_MODEL` | `claude-haiku-4-5` |
   | `NOTION_TOKEN` | секрет интеграции Notion |
   | `NOTION_PUBLIC_DOMAIN` | `mirror-psychology-ae8.notion.site` |
   | `GOOGLE_SHEET_VYRABOTKA` | ID таблицы «Выработка» |
   | `GOOGLE_SHEET_PLANY` | ID таблицы «Планы» |
   | `PM_IDS` | ID проджект-менеджеров через запятую |
   | `KOMPLEKT_IDS` | ID комплектаторов через запятую |
   | `REFRESH_INTERVAL_MIN` | `60` |
   | `GOOGLE_CREDENTIALS_JSON` | **всё содержимое** файла `google_credentials.json` (открыть, скопировать целиком, вставить) |

   > Ключ Google на хостинг передаём не файлом, а текстом — переменной
   > `GOOGLE_CREDENTIALS_JSON`. Бот сам создаст из неё файл при старте.

5. Railway передеплоит проект. Откройте **Deployments → Logs** — дождитесь строк
   «Индекс… построен», «Claude подключён», «Google Sheets подключены», «Бот запущен».
6. Проверьте бота в Telegram. Готово — Mac можно выключать.

> Тариф: бесплатного пробного кредита хватит на тесты; для постоянной работы нужен
> план **Hobby** (~$5/мес + плата за память; для нашего бота обычно ~$10–15/мес).

## Вариант B — VPS (небольшой сервер, дешевле и предсказуемее)

Подойдёт сервер с **2 ГБ RAM** (напр. Hetzner CX22 ~€4/мес, Timeweb/Beget ~300–400 ₽/мес).
Нужен минимальный навык работы в терминале по SSH — я помогу с командами.

Кратко:
1. Создаёте сервер (Ubuntu 22.04+), подключаетесь по SSH.
2. Ставите Python и git, клонируете репозиторий, создаёте `.env` и
   `google_credentials.json`.
3. Запускаете бота как службу (systemd) — тогда он стартует сам и переживает
   перезагрузки.

Готовый файл службы — `deploy/corporatebot.service` (пути внутри поправить под сервер).
Пошаговые команды под ваш сервер дам, когда выберете провайдера.

## После запуска

- Обновили базу в Notion → бот сам перечитает по расписанию (`REFRESH_INTERVAL_MIN`),
  либо нажмите «🔄 Обновить базу» в боте.
- Обновили код (новые функции) → на Railway это авто-деплой при push в ветку; на VPS —
  `git pull` и перезапуск службы.
- Автоматический вебхук Notion (чтобы изменения прилетали мгновенно) можно включить
  позже — он требует публичного адреса, который на хостинге уже есть.
