# Инструкция по запуску (Mac) — этапы 0–1

Делается один раз. Дальше на каждом этапе — просто `git pull` и перезапуск.

---

## Часть 1. Получить ключи (этап 0) — 5 минут

1. **Токен бота.** В Telegram откройте **@BotFather** → команда `/newbot` →
   задайте имя и username (username должен оканчиваться на `bot`).
   Скопируйте токен вида `7712...:AAH...`.

2. **Ваш Telegram ID.** Напишите боту **@userinfobot** — он пришлёт числовой `Id`.
   Запишите это число.

> Ключ Claude, Notion и Google понадобятся на этапах 2–7 — сейчас не нужны.

---

## Часть 2. Установить и запустить (этап 1) — 5 минут

Откройте **Терминал** (Cmd+Пробел → «Терминал» → Enter) и вставляйте команды по одной.

1. **Проверить Python** (нужен 3.10+):
   ```bash
   python3 --version
   ```
   Если команды нет — установите Python с https://www.python.org/downloads/ и повторите.

2. **Скачать код:**
   ```bash
   cd ~
   git clone https://github.com/nikolayanisimov922-itmo/CorporateBot.git
   cd CorporateBot
   ```
   > Если папка уже была скачана — вместо clone: `cd ~/CorporateBot && git pull`

3. **Переключиться на рабочую ветку:**
   ```bash
   git checkout claude/tender-darwin-pjbv25
   ```

4. **Установить окружение и библиотеки:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   > Значок `(.venv)` слева в строке терминала = окружение включено. Так и должно быть.

5. **Создать файл настроек:**
   ```bash
   cp .env.example .env
   open -e .env
   ```
   В открывшемся файле впишите два значения и сохраните (Cmd+S):
   ```
   BOT_TOKEN=сюда_токен_из_BotFather
   ADMIN_ID=сюда_ваш_числовой_id
   ```
   Остальные строки пока оставьте пустыми.

6. **Запустить бота:**
   ```bash
   python bot.py
   ```
   В терминале появится строка `Бот запущен: @ваш_бот`. Готово.

---

## Часть 3. Проверка ✅

- Откройте своего бота в Telegram, нажмите **Start** (или отправьте `/start`).
- Должно появиться приветствие и меню с кнопками:
  **📚 База знаний · 📤 Передать данные · 📢 Рассылка · ℹ️ Помощь**
- Кнопка **📢 Рассылка** видна только вам (проверка `ADMIN_ID`).
- Кнопки пока отвечают заглушками — это нормально, наполним дальше.

**Остановить бота:** в терминале нажмите `Ctrl+C`.
**Запустить снова позже:**
```bash
cd ~/CorporateBot
source .venv/bin/activate
python bot.py
```

# Этап 2. Подключить Notion — выгрузка базы

Цель: бот читает всю вашу базу знаний из Notion.

## Часть 1. Получить доступ к Notion — 5 минут

1. **Создать интеграцию.** Откройте https://www.notion.so/my-integrations →
   **New integration** → тип **Internal** → задайте имя (напр. «CorporateBot») → сохраните.
   Скопируйте **Internal Integration Secret** (начинается на `secret_` или `ntn_`).

2. **Открыть доступ интеграции к базе.** Зайдите на **головную страницу** вашей
   базы знаний в Notion → кнопка **•••** (вверху справа) → **Connections**
   (Подключения) → выберите вашу интеграцию «CorporateBot».
   > Важно: доступ открывается на головную страницу — подстраницы подхватятся сами.

3. **Скопировать ссылку на головную страницу.** На той же странице: **•••** →
   **Copy link** (Копировать ссылку). Это и есть `NOTION_ROOT_PAGE`.

## Часть 2. Вписать ключи и запустить выгрузку

1. Обновите код и библиотеки:
   ```bash
   cd ~/CorporateBot
   git pull
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Откройте настройки и впишите два значения:
   ```bash
   open -e .env
   ```
   ```
   NOTION_TOKEN=secret_ваш_секрет_интеграции
   NOTION_ROOT_PAGE=https://www.notion.so/ссылка_на_головную_страницу
   ```
   Сохраните (Cmd+S).

3. Запустите выгрузку:
   ```bash
   python sync_notion.py
   ```

## Проверка ✅

В терминале появится список страниц и итог **«Загружено N страниц»**.
Сверьте число со своей базой в Notion — должно совпасть (головная + все подстраницы).
Результат сохранится в файл `data/knowledge_base.json`.

> Если увидите «Загружено 0 страниц» или ошибку доступа — почти всегда это значит,
> что интеграция не подключена к головной странице (шаг 2 выше). Подключите и повторите
> `python sync_notion.py`.
>
> Диагностика: `python notion_check.py` покажет, какие страницы видит интеграция.

# Этап 3. Поиск по базе (RAG)

Цель: по вопросу находятся нужные куски именно из вашей базы. Пока без ответа
Claude — проверяем сам поиск. Поиск работает локально и бесплатно.

## Часть 1. Построить поисковый индекс

```bash
cd ~/CorporateBot
git pull
source .venv/bin/activate
pip install -r requirements.txt
python build_index.py
```

> При **первом** запуске `build_index.py` скачает поисковую модель (~470 МБ).
> Это один раз и занимает пару минут. Дальше поиск работает без интернета.
> Строку `pip install` могут занять 5–10 минут (ставится модель-движок) — это нормально.

В конце появится: **«Индекс построен: N кусков из M страниц»**.

## Часть 2. Проверить поиск

```bash
python search_cli.py
```

Введите пару рабочих вопросов (например, «как оформить отпуск» или что-то из вашей
практики). Скрипт покажет **заголовки страниц-источников**, откуда возьмётся ответ,
и короткие фрагменты. Выход — пустая строка или `exit`.

## Проверка ✅

На ваши вопросы источники **релевантные** (те страницы, где реально есть ответ) —
значит поиск работает. На этапе 4 подключим Claude, чтобы он писал готовый ответ
по этим найденным кускам.

> Если добавите/измените страницы в Notion — обновите базу и индекс:
> `python sync_notion.py && python build_index.py`

# Этап 4. Режим «База знаний» — Claude отвечает

Цель: сотрудник жмёт «📚 База знаний», задаёт вопрос — Claude пишет ответ строго
по вашей базе и даёт ссылку на страницу Notion.

## Часть 1. Вписать ключ Claude

1. Возьмите ключ из https://console.anthropic.com → **API Keys** (начинается на `sk-ant-...`).
   > В консоли Anthropic желательно сразу поставить лимит трат (напр. $20/мес),
   > раздел **Limits** — тогда неожиданного счёта не будет.

2. Обновите код и впишите ключ:
   ```bash
   cd ~/CorporateBot
   git pull
   source .venv/bin/activate
   pip install -r requirements.txt
   open -e .env
   ```
   В `.env`:
   ```
   ANTHROPIC_API_KEY=sk-ant-ваш_ключ
   ```
   (строку `ANTHROPIC_MODEL=claude-haiku-4-5` не трогайте — это эконом-модель по умолчанию.)

## Часть 2. Запустить бота

```bash
python bot.py
```

В логе должно появиться: «Поисковый индекс загружен» и «Claude подключён».

## Проверка ✅

В Telegram: `/start` → **📚 База знаний** → задайте 5–10 реальных рабочих вопросов.
Бот отвечает текстом по делу + ссылка на страницу Notion. На вопрос «не из базы» —
честно говорит, что информации нет. Кнопка «⬅️ Выйти в меню» — вернуться назад.

> Ответы слишком длинные/короткие или не тот стиль — скажите мне, я подстрою.

# Этап 5. Актуальность базы

Цель: изменили Notion — бот знает свежее.

## Что появилось

1. **Кнопка «🔄 Обновить базу»** в меню (видна только вам как админу) —
   перечитывает Notion и перестраивает поиск прямо на ходу, без терминала.
2. **Автообновление по расписанию** — бот сам перечитывает Notion раз в час
   (пока запущен). Частоту можно изменить в `.env`: `REFRESH_INTERVAL_MIN=60`
   (поставьте `0`, чтобы выключить).

## Как запустить

```bash
cd ~/CorporateBot
git pull
source .venv/bin/activate
python bot.py
```

## Проверка ✅

1. Добавьте абзац на любую страницу в Notion (что-то заметное).
2. В боте: главное меню → **🔄 Обновить базу** → дождитесь «✅ База обновлена: N страниц».
3. Задайте вопрос по новому абзацу через «📚 База знаний» — бот отвечает уже с учётом свежего.

> Полностью автоматический вебхук («Notion сам толкает боту изменения») требует
> публичного адреса — включим на этапе 9 (хостинг). До тех пор кнопка + расписание
> полностью закрывают задачу.

---

## Если что-то пошло не так

- `BOT_TOKEN не задан` — вы не сохранили `.env` или оставили токен пустым.
- `Unauthorized` — токен скопирован с ошибкой, возьмите заново у @BotFather.
- Кнопки «Рассылка» нет — проверьте, что `ADMIN_ID` = ваш ID из @userinfobot,
  и отправьте `/start` заново.
- Любая другая ошибка — скопируйте текст из терминала и пришлите мне, разберёмся.
